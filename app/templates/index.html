OpenFish Python Branch

Browser screenshot analysis with a Python-first backend

Capture a monitor, window, or tab in the browser, send the image to the Python backend, and render a structured VLM plan directly in the interface.

To capture a specific monitor, choose Entire Screen in the browser picker and select the display you want. The backend runs in Python; the browser still handles screen capture.
